# Toolkit Docs

本目录存放 dsh-developer-toolkit 的补充文档。

当前内容：

- 插件矩阵与风险分级：见根目录 `README.md`
- 兼容版本：见根目录 `README.md` 的 Compatibility 一节
- Roadmap：见根目录 `README.md` 的 Roadmap 一节

本仓库不复制任何插件源码。每个插件保持独立仓库、独立安装。

## 维护约定

- 插件状态变化时同步更新根目录 `README.md` 的矩阵
- 新增插件需先经过 Release Readiness 检查，再决定是否加入矩阵
- 截图统一放根目录 `screenshots/`，使用 PNG，单张不超过 500 KB
